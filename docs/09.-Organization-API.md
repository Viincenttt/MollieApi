### Get current organization
Retrieve the currently authenticated organization.
```C#
using IOrganizationClient client = new OrganizationClient("{yourApiKey}");
MollieResult<OrganizationResponse> result = await client.GetCurrentOrganizationAsync();
OrganizationResponse organizationResponse = result.Data;
```

### Get organization
```C#
using IOrganizationClient client = new OrganizationClient("{yourApiKey}");
```
