### Create a new refund
```c#
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult<RefundResponse> result = await this._refundClient.CreatePaymentRefundAsync("{paymentId}", new RefundRequest() {
	Amount = new Amount(Currency.EUR, 100.00m),
	Description = "{description}"
});
RefundResponse refundResponse = result.Data;
```

### Retrieve a refund by payment and refund id
```c#
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult<RefundResponse> result = await this._refundClient.GetPaymentRefundAsync("{paymentId}", "{refundId}");
RefundResponse refundResponse = result.Data;
```

### List payment refunds
Mollie allows you to set offset and count properties so you can paginate the list. The offset and count parameters are optional.
```c#
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult<ListResponse<RefundResponse>> result = await this._refundClient.GetPaymentRefundListAsync("{paymentId}", "{offset}", "{count}");
ListResponse<RefundResponse> refundList = result.Data;
```

### Cancel a payment refund
```c#
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult result = await refundClient.CancelPaymentRefundAsync("{paymentId}", "{refundId}");
```

### Create order refund
When using the Orders API, refunds should be made against the Order. When using pay after delivery payment methods such as Klarna Pay later and Klarna Slice it, this ensures that your customer will receive credit invoices with the correct product information on them and generally have a great experience.
```c#
OrderRefundRequest orderRefundRequest = new OrderRefundRequest() {
	Lines = new List<OrderLineDetails>() {
		Id = {orderLineId},
		Quantity = 5,
		Amount = new Amount("EUR", 5.00m)
	},
	Description = ""
};
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult<OrderRefundResponse> result = await refundClient.CreateOrderRefundAsync({orderId}, orderRefundRequest);
OrderRefundResponse orderRefundResponse = result.Data;
```

### List order refunds
Retrieve all order refunds.
```C#
using IRefundClient refundClient = new RefundClient("{yourApiKey}");
MollieResult<ListResponse<RefundResponse>> result = await refundClient.GetOrderRefundListAsync({orderId});
ListResponse<RefundResponse> refundList = result.Data;
```
