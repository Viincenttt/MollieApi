### Creating a new customer
Customers will appear in the Mollie Dashboard where you can manage their details, and also view their payments and subscriptions.
```c#
CustomerRequest customerRequest = new CustomerRequest() {
	Email = "{email}",
	Name = "{name}",
	Locale = Locale.nl_NL
};

using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
MollieResult<CustomerResponse> result = await customerClient.CreateCustomerAsync(customerRequest);
CustomerResponse customerResponse = result.Data;
```

### Retrieve a customer by id
Retrieve a single customer by its ID.
```c#
using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
MollieResult<CustomerResponse> result = await customerClient.GetCustomerAsync(customerId);
CustomerResponse customerResponse = result.Data;
```

### Retrieve customer list
Mollie allows you to set offset and count properties so you can paginate the list. The offset and count parameters are optional.
```c#
using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
MollieResult<ListResponse<CustomerResponse>> result = await customerClient.GetCustomerListAsync();
ListResponse<CustomerResponse> response = result.Data;
```

### Updating a customer
Update an existing customer.
```c#
using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
CustomerRequest updateParameters = new CustomerRequest() {
	Name = "{customerName}"
};
MollieResult<CustomerResponse> result = await customerClient.UpdateCustomerAsync("{customerIdToUpdate}", updateParameters);
CustomerResponse customerResponse = result.Data;
```

### Deleting a customer
Delete a customer. All mandates and subscriptions created for this customer will be canceled as well.
```c#
using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
MollieResult result = await customerClient.DeleteCustomerAsync("{customerIdToDelete}");
```

### Create customer payment
Creates a payment for the customer.
```c#
PaymentRequest paymentRequest = new PaymentRequest() {
    Amount = new Amount(Currency.EUR, 100.00m),
    Description = "{description}",
    RedirectUrl = this.DefaultRedirectUrl,
};
using ICustomerClient customerClient = new CustomerClient("{yourApiKey}");
MollieResult<PaymentResponse> result = await customerClient.CreateCustomerPayment({customerId}, paymentRequest);
PaymentResponse paymentResponse = result.Data;
```
