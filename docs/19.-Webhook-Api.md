This API is used to create, list, update and delete [next-gen webhooks](https://docs.mollie.com/reference/webhooks-new).

### Creating a webhook
```c#
var request = new WebhookRequest {
	Name = "my-webhook",
	Url = "https://github.com/Viincenttt/MollieApi/",
	EventTypes = [WebhookEventTypes.PaymentLinkPaid, WebhookEventTypes.SalesInvoiceCreated],
	Testmode = true
};

using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult<WebhookResponse> result = await client.CreateWebhookAsync(request);
WebhookResponse response = result.Data;
```

### Retrieve webhook list
Mollie allows you to set offset and count properties so you can paginate the list. The offset and count parameters are optional.
```c#
using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult<ListResponse<WebhookResponse>> result = await client.GetWebhookListAsync();
ListResponse<WebhookResponse> response = result.Data;
```

### Retrieve a webhook by id
```c#
using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult<WebhookResponse> result = await client.GetWebhookAsync("{your-webhook-id}");
WebhookResponse response = result.Data;
```

### Update a webhook
```c#
var updateRequest = new WebhookRequest {
	Name = "my-webhook-updated",
	Url = "https://github.com/Viincenttt/MollieApi/-updated",
	EventTypes = [WebhookEventTypes.PaymentLinkPaid, WebhookEventTypes.SalesInvoiceCreated],
	Testmode = true
};
using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult<WebhookResponse> result = await client.UpdateWebhookAsync(created.Id, updateRequest);
WebhookResponse updated = result.Data;
```

### Delete a webhook
```c#
using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult result = await client.DeleteWebhookAsync("{webhook-id-to-delete}", testmode: true);
```

### Test a webhook
```c#
using IWebhookClient client = new WebhookClient("{yourKey}");
MollieResult result = await client.TestWebhookAsync(created.Id, testmode: true);
```
