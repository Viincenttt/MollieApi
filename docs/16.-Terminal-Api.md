## List terminals
Retrieve all point-of-sale terminal devices linked to your organization or profile, ordered from newest to oldest.
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
MollieResult<ListResponse<TerminalResponse>> result = await client.GetTerminalListAsync();
ListResponse<TerminalResponse> response = result.Data;
```

### Get terminal by id
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
MollieResult<TerminalResponse> result = await client.GetTerminalAsync({yourTerminalId});
TerminalResponse response = result.Data;
```

## Terminal pairing codes
Pairing codes are used to onboard a point-of-sale terminal. A pairing code can be used multiple times and expires after 90 days. These endpoints do not support test mode.

### Request terminal pairing code
Set `includeQrCode` to `true` to receive a QR code that can be scanned by the terminal, in addition to the human-readable code.
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
TerminalPairingCodeRequest request = new TerminalPairingCodeRequest {
    ProfileId = {yourProfileId}
};
MollieResult<TerminalPairingCodeResponse> result = await client.CreateTerminalPairingCodeAsync(request, includeQrCode: true);
TerminalPairingCodeResponse response = result.Data;
string code = response.Code;
string? qrCodeSrc = response.Details?.QrCode?.Src;
```

### List terminal pairing codes
Returns all pairing codes, including active, expired and revoked codes.
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
MollieResult<ListResponse<TerminalPairingCodeResponse>> result = await client.GetTerminalPairingCodeListAsync();
ListResponse<TerminalPairingCodeResponse> response = result.Data;
```

### Get terminal pairing code
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
MollieResult<TerminalPairingCodeResponse> result = await client.GetTerminalPairingCodeAsync({yourPairingCodeId}, includeQrCode: true);
TerminalPairingCodeResponse response = result.Data;
```

### Revoke terminal pairing code
Revoking a pairing code prevents new terminals from being paired with it. Terminals that have already been paired are not affected.
```C#
using ITerminalClient client = new TerminalClient({yourApiKey});
MollieResult<TerminalPairingCodeResponse> result = await client.RevokeTerminalPairingCodeAsync({yourPairingCodeId});
TerminalPairingCodeResponse response = result.Data;
```
